# 开放性主观题清单（无唯一标准答案）

本文档单独列出专业试卷中“开放性”或“参考答案非唯一”的主观题。
这些题已配置 `scoring_points`，但机器分只作参考，**默认建议人工复核**。

字段说明：

- `open_ended=true`：标记为开放性/非唯一答案题
- `open_ended_kind`：`fully_open` 完全开放；`multi_valid` 一题多解
- `open_ended_note`：开放原因
- `require_manual_review=true`：建议强制人工复核

合计：**4** 题

## 1. 电气 / electrical / q43

- **类型**：完全开放（无唯一标准答案）
- **分值**：20.0
- **题干**：请阐述自己从事电气工程或自动化专业工作后的打算和想法
- **参考答案**：答案各自发挥
- **开放原因**：参考答案为“答案各自发挥”，无唯一标准答案。
- **评分说明**：仅按主题相关性与表述完整性给参考分，必须人工复核。
- **人工复核**：是
- **当前评分点**：
  - `q43_p1` [10.0] 围绕电气工程或自动化专业工作后的打算和想法展开
  - `q43_p2` [10.0] 表述完整、主题明确（参考答案为各自发挥）

## 2. 环保专业 / environmental / q44

- **类型**：一题多解/示例答案（参考答案非唯一）
- **分值**：10.0
- **题干**：你对当前我公司的环保形式有哪些了解(在环保上有哪些重要工作)?(至少有2点符合公司环保形式,每点5分,共10分)
- **参考答案**：(1)超低排放;(2)清江行动;(3)钢渣清理;(4)除尘改造;(5)棚化改造;(5)清污分流(雨污分流);(6)噪声整理;(7)209号文件;(8)脱硫脱销(烟气脱硫);(9)危废库建设;(10)煤气均压煤气回收改造;(11)皮带转运站通廊封闭;(12)花园式工厂改造等;(13)除尘灰气力输送等。
- **开放原因**：题干要求结合本公司环保实际至少答2点；参考答案是示例清单，不是唯一固定表述。
- **评分说明**：评分点按参考答案中的示例工作项覆盖给分；同义表述/公司实际工作应人工确认。
- **人工复核**：是
- **当前评分点**：
  - `q44_p1` [5.0] 答出参考答案中的公司环保工作之一（如超低排放、清江行动、钢渣清理、除尘改造、棚化改造、清污分流、脱硫脱硝等）
  - `q44_p2` [5.0] 答出参考答案中的公司环保工作之二

- **分值**：15.0

输入:

输出:

请使用js、java、C、C#、python中的任意一种来实现

- **评分说明**：答题页提供语言下拉；按“在数组中查找目标并返回索引”核心点与所选语言参考答案评分。
- **人工复核**：是
- **当前评分点**（默认）：
  - `q21_p1` [3.0] 接收数组与目标元素作为输入
  - `q21_p2` [7.0] 遍历或查找数组元素位置
  - `q21_p3` [3.0] 返回目标元素下标或未找到标记
  - `q21_p4` [2.0] 代码表达式或函数调用结构完整

## 使用建议

1. 自动评分可给出参考分，但开放题最终分以人工复核为准。
2. `fully_open` 题不要强求与参考答案字面一致。
3. `multi_valid` 题只要覆盖评分点语义/结构即可，允许不同语言、不同表述、不同示例。
4. 后续新增开放题时，请同步更新本题清单，并在题目 JSON 中设置 `open_ended` 相关字段。
