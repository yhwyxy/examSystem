# 试卷预览功能设计文档

## 概述

在管理后台的试卷/专业列表中添加"预览"功能，让管理员可以直接查看试卷在考试端的效果，无需先发布试卷、进入考试、输入姓名和工号。

## 功能需求

1. **预览入口**：在试卷列表的操作列添加"预览"按钮
2. **预览页面**：复用考试端页面，添加预览模式
3. **答案展示**：默认显示答案，支持切换隐藏
4. **预览标识**：明确标识当前为预览模式

## 技术方案

### 1. 后端API

**新增端点：** `GET /api/admin/papers/{slug}/preview`

- 需要管理员认证
- 返回完整试卷数据（包括答案）
- 跳过"试卷必须开考"的验证

### 2. 前端修改

#### papers.js
- 在 `renderPapersList()` 中添加"预览"按钮
- 添加点击事件，打开预览页面

#### exam.js
- 检测URL参数 `preview=true`
- 预览模式下：
  - 跳过登录验证
  - 直接加载试卷
  - 默认显示答案
  - 添加切换按钮
  - 禁用提交功能

#### exam.html
- 添加预览模式横幅

#### style.css
- 添加预览横幅样式
- 添加答案显示样式

## 实现细节

### URL格式
```
/exam?paper={slug}&preview=true
```

### 预览模式行为
1. **页面加载**：跳过登录，直接显示试卷
2. **答案显示**：默认显示答案，可切换隐藏
3. **提交功能**：禁用提交，点击后显示预览提示
4. **页面标识**：顶部显示预览模式横幅

### 答案显示格式
```
题目：xxx
A. 选项1
B. 选项2 ✓
C. 选项3
D. 选项4

┌─────────────────────────────────────┐
│ 正确答案：B                         │
│ 解析：xxx                           │
└─────────────────────────────────────┘
```

### 切换按钮
- 位置：预览横幅右侧
- 功能：在"题目+答案"和"仅题目"之间切换
- 默认状态：显示答案

## 文件修改清单

1. `backend/main.py` - 添加预览API端点
2. `frontend/js/papers.js` - 添加预览按钮
3. `frontend/js/exam.js` - 添加预览模式逻辑
4. `frontend/css/style.css` - 添加预览样式

## 测试用例

1. 点击预览按钮，正确打开预览页面
2. 预览模式下显示试卷内容
3. 默认显示答案
4. 切换按钮可隐藏/显示答案
5. 提交功能在预览模式下禁用
6. 预览模式标识清晰可见
