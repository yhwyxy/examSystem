# 复合主观题与代码语言选择设计

## 背景与目标

考试端目前为所有主观题渲染一个答案输入框，无法表达同一道大题的多个独立小问；代码题的语言也只能由试卷固定配置，考生无法在允许范围内选择。目标是在保持普通题和历史答卷兼容的前提下：

- 支持大题下的显式 `subquestions`，每个小问独立输入、评分和复核。
- 支持代码小问的允许语言白名单和考试端下拉选择。
- 将现有 18 份试卷中可可靠识别的小问迁移到新结构。
- 使用 subjective-scoring v0.1.7 分别评分并汇总大题、整卷得分。

## 数据模型

普通题的现有格式保持不变。复合题使用 `type: "composite"`，大题的 `score` 必须等于小问分值之和：

```json
{
  "id": "q41",
  "type": "composite",
  "question": "回答下列问题",
  "score": 10,
  "subquestions": [
    {
      "id": "q41-1",
      "question": "说明 HTTP 与 HTTPS 的区别。",
      "score": 5,
      "answer": "...",
      "scoring_mode": "text"
    },
    {
      "id": "q41-2",
      "question": "编写对应程序。",
      "score": 5,
      "answer": "...",
      "scoring_mode": "code",
      "allowed_languages": ["javascript", "typescript"]
    }
  ]
}
```

每个小问可使用 `text`、`sql`、`code` 或 `calculation` 评分模式。代码模式必须配置非空且不重复的 `allowed_languages`。旧的单值 `code_language` 在加载时兼容为单元素白名单。服务端只信任试卷配置，不接受客户端提交的分值、模式或语言白名单。

## 评分与提交链路

复合题答案使用嵌套对象提交：

```json
{
  "q41": {
    "q41-1": {"answer": "..."},
    "q41-2": {"answer": "...", "language": "javascript"}
  }
}
```

服务端校验主问题和小问 ID；代码小问的 `language` 必须属于该小问白名单。每个小问独立构造 subjective-scoring v0.1.7 请求，分别保存得分、置信度、原因和复核状态。大题得分为小问得分之和，整卷仍按现有流程汇总。未填写的小问作为空答案独立计 0 分。单个小问远程评分失败时沿用现有降级和复核机制，不阻塞同题其他小问。

## 考试端交互

复合题显示大题题干和总分，随后按顺序显示每个小问的编号、题干、分值和独立输入区。文本小问使用多行输入框；代码小问使用代码样式输入框和语言下拉框。下拉框仅显示 `allowed_languages`，默认第一项；即使只有一种语言也保留下拉控件。切换语言不清空代码。未配置 `subquestions` 的题目保持现有渲染和答案收集逻辑。

## 管理端、复核与导出

成绩详情按“大题 -> 小问”展示答案、所选语言、得分、满分、置信度、评分原因和复核状态。复核修改小问分数后自动重算大题和整卷总分。试卷编辑器支持添加、删除、排序小问，配置分值、评分模式和语言白名单。导出结果保留大题编号，分别列出小问，并为代码答案标注语言。

## 试卷迁移范围

本次不自动猜测全部试卷中的小问，只迁移以下用户确认的题目：

- 机械 A 卷 `mechanical.json`：`q41`、`q44`。
- 材料专业 `materials.json`：`q42`、`q43`。
- 测控 `instrumentation.json`：`q41`、`q42`，并补回遗漏的 `q43` 计算题。
- 化学分析 `chemical-analysis.json`：`q42`、`q43`。
- 化学工程 `chemical-engineering.json`：`q42`、`q44`。
- 金属材料 `metal-materials.json`：`q43`。
- 法务 `legal.json`：将案例背景设为一个父题干，把原 Word 中 7 个问题及对应答案设为子题。

除测控新增题外，原题未标小问分值时平均分配，最后一问吸收舍入差额，确保大题分值和整卷总分不变。测控遗漏的 `q43` 满分 20 分，包含测量范围、量程和三个输出点三个子问；补回后该卷总分由 80 分恢复为 100 分。该题使用 `calculation` 模式，并按子问配置预期数值、单位和容差。

法务案例以原 Word 为权威来源，重建 7 个子题及参考答案，分值依次为 4、5、5、5、5、4、4，总计 32 分。当前 JSON 中重复的案例背景、遗漏的第 1 问答案和错误题目边界不得保留。

迁移生成机器可读报告，记录每道题的拆分、分值、来源和跳过原因。验证除测控卷增加 20 分外，其他试卷迁移前后总分一致。

## 错误处理与兼容性

- 复合题缺少小问、ID 重复、分值不一致或代码白名单非法时拒绝加载，并指出大题和小问。
- 提交未知小问、错误答案结构或非法语言时返回明确的 422 错误。
- 普通题 JSON、旧的单值 `code_language` 和历史答卷继续可读。
- 客户端不能通过提交载荷改变服务端评分配置。
